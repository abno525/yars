# M19 and M20 — land the work, then hygiene and CI

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Read `2026-11-11-yars-roadmap-to-v1.md` first. Steps use checkbox (`- [ ]`) syntax.

**Goal:** every commit is on GitHub and in a reviewable PR, and every later push is checked by CI.

**Architecture:** no code changes in M19: the six new PR branches are pointers at commits that already exist on `feat/redesign`, in order, so nothing is cherry-picked and nothing can conflict. M20 is one small branch on top.

**Spec:** the user's rule: stacked PRs, each under 8,000 changed lines and 500 files, never merged by Claude.

## Review focus

1. A branch tip whose tests fail on its own (a fix for it sits in a later commit): the PR must still be reviewable, so the tip moves forward to the first commit that passes (M19 task 2).
2. CI on a machine without pandoc or xelatex must pass, not fail (M20 task 4).
3. `.gitignore` must not hide files the tests or the build need (M20 task 2).

### Task 4: CI

**Files:** create `.github/workflows/ci.yml`

- [ ] **Step 1:** write exactly:

```yaml
name: ci
on:
  push:
    branches: [master, feat/redesign, "pr/**"]
  pull_request:
jobs:
  test:
    runs-on: ubuntu-latest
    timeout-minutes: 20
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version-file: go.mod
      - name: git identity for the tests
        run: |
          git config --global user.name ci
          git config --global user.email ci@yars.local
          git config --global init.defaultBranch main
      - name: tidy
        run: go mod tidy -diff
      - name: format
        run: test -z "$(gofmt -l .)"
      - name: vet
        run: go vet ./...
      - name: test
        run: go test ./...
      - name: race
        run: go test -race ./internal/store ./internal/db ./internal/index ./internal/events ./internal/web
```

  pandoc and xelatex are not installed on purpose: the tests that need them call `t.Skip` (`internal/export/export_test.go:145`, `:235`, `internal/export/m16_test.go:378`, `:381`).
