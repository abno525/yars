# Security

## Report a vulnerability

Report it in private: <https://github.com/abno525/yars/security/advisories/new>.

Do not open a public issue for a security problem.

Say what you did, what happened and what you expected. Name the version (`yars version`). Use made-up data: no real finding, client name, host or token.

A fix is released before the details are published. The advisory credits you unless you ask otherwise.

## Supported versions

Fixes go into the latest release. Before 1.0 that is the `master` branch.
